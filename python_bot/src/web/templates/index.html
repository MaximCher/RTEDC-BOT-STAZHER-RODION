Админы / менеджеры
Staff получают уведомления о лидах. Админка (Mini App) — только для admin.
Ссылка появится здесь…
Откройте ссылку или отправьте её сотруднику. По переходу бот добавит пользователя в staff.
Доступ / виральность (обязательные подписки)
Если список пуст — бот никого не проверяет. Добавьте каналы/группы, чтобы перед входом просить подписку. Можно просто вставлять ссылки Telegram — бот сам разберётся.
Примеры: https://t.me/srvt_news, @srvt_news, -1001234567890
Если вставите инвайт вида https://t.me/+..., бот сможет дать кнопку “Открыть”, но проверить подписку автоматически не сможет.
Рассылки (планирование)
Сообщение будет отправлено всем пользователям, которые попали в базу (users).
Время берётся как введено в форме (без часового пояса).
События (журнал)
Журнал действий из таблицы events. Удобно для диагностики и “пути пользователя”.
Топ действий
По action и по человекочитаемому описанию.
